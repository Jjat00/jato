# jato.run

Landing de [jato.run](https://jato.run): los proyectos de Jaime Aza que viven bajo `*.jato.run`.

Astro 7 estático + Tailwind v4, en español (`/`) e inglés (`/en/`). El texto y la lista de proyectos están en `src/i18n/copy.js`.

```bash
npm install
npm run dev     # http://localhost:4321
npm run build   # dist/
```
